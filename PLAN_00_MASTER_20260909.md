## 2. Two findings the milestone docs do not yet carry

### Finding 1 — `main` is red. This blocks every other milestone.

PR #34 added the fixture-provenance gate and wired it into `eev2-harness-ci.yml` as the *first* CI step. It was merged **without fixing the fixture it was built to catch.** `apps-script/EEV2CitationTruncationRegression.gs:65` — the EEV2-008/009 PO-5578-007 fixture — contains 7 literal `\n\n` sequences with no `// KNOWN-SYNTHETIC:` justification.

Consequence: `npm run check:fixtures` exits 1, so **any PR touching `apps-script/**` now fails CI before the regression suite even runs.** The M3 fix cannot go green until this is cleared. This is not a big job — it is a 15-minute job — but it is strictly first.

### Finding 2 — M7's code is already merged; the milestone text is stale.

`PROJECT_MILESTONES.md` records M7 as "BUILT, NOT MERGED". `EEV2AuditJob.gs` is on `main` at commit `fd2a06f`. The real remaining blocker is only the live-run step. And that blocker is smaller than recorded: the file's own header says `eev2AuditJob` can be run from the **Apps Script editor function dropdown** — no API-executable deployment needed. `clasp run` needs the extra deployment; the editor does not. M7 can close this week without creating any new deployment.

### Both are the same disease

This project's recorded failure mechanism is *acting on a belief about current state that nobody re-checked.* Both findings above are that mechanism, caught again. The counter-measure already exists — `scripts/session-context.sh` — but it deliberately excludes CI status. **Recommendation: add one line to it that prints whether the last `main` CI run passed.** Cost: zero. See `PLAN_01`.

## 6. The one rule that makes this plan work

Every real-document test in this plan costs a Gemini call and produces an email. So:

**One change per submission. Never batch two fixes into one real-fire test.** If a submission behaves unexpectedly, you must be able to name which change caused it without guessing. This is the cheapest insurance available and it costs nothing but discipline.

Corollary, already in `EEV2_011`: **do not re-run Test A against unfixed code.** It only resends the same fabricated figure.
